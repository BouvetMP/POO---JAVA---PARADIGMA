# Encapsulamiento

## Definición
Este paradigma trata de proteger los atributos de una clase mediante un sellado y acceso controlado a sus datos llevado a cabo por los modificadores (Publico, Privado, Protegido) al igual que con los métodos get y set.

## Idea Clave
Lo clave de este paradigma es que protege los atributos de una clase para evitar su mala manipulación.

## Clases Ejemplo
Clase: Cuenta Bancaria
Representa la lógica de una cuenta bancaria con los atributos y metodos para
el manejo de la misma.

Clase: Main
Crea un objeto del tipo cuenta Bancaria y realiza operaciones en ese objeto,
tambien es el punto de arranque del programa.

## Como Ejecutar
1. Abrir la carpeta del proyecto
2. Darle click a la opción "Run" estando en la clase Main

## Aprendizaje
Que este paradigma ayuda mucho en la construcción de objetos ya que impide que los atributos cambien de forma aleatoria o por un error, de esa forma se asegura que el resultado sea el esperado.
